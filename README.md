# Tech Elite | موقع دفعة تقنية المعلومات

هذا المشروع نسخة أولية لتصميم موقع Tech Elite. الواجهة الرئيسية تحتوي شعار الدفعة، طالبًا على الكمبيوتر، تصميمًا متجاوبًا، ووضعين قابلين للتبديل؛ بنفسجي/وردي ليلي، وأبيض/أزرق نهاري.

## معاينة سريعة بدون تثبيت
افتح الملف `demo.html` باستخدام Chrome. ستجد الرئيسية والأقسام الأولية وزر تبديل الوضعين. هذه **معاينة HTML مستقلة**؛ النسخة الرئيسية المبرمجة بـReact تتضمن صفحات فعلية للخطة والمكتبة والبحث وتفاصيل المقررات.

## تشغيل الموقع الكامل باستخدام React

تحتاج Node.js LTS واتصالًا بالإنترنت لتنزيل حزم المشروع لأول مرة. افتح المجلد في VS Code ثم شغّل:

```bash
npm install
npm run dev
```

ستظهر لك وصلة محلية، غالبًا `http://localhost:5173/`. للبناء النهائي:

```bash
npm run build
```

الناتج في مجلد `dist`.

## الاستضافة المجانية على Cloudflare Pages

ارفع المشروع إلى GitHub ثم اربطه بخدمة Cloudflare Pages، بالضبط بالإعدادات التالية:

- Framework preset: React (Vite)
- Build command: `npm run build`
- Build output directory: `dist`

أو بعد البناء محليًا يمكنك رفع مجلد `dist` مباشرةً بواسطة Cloudflare Pages Direct Upload.

المصدر: https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/

## تعديل محتوى المواد

- افتح `src/data.ts`.
- `siteConfig` خاص باسم الدفعة والجامعة.
- `courses` قائمة مواد **تجريبية فقط** إلى أن يتم إدراج خطة الجامعة الرسمية.
- لكل مادة: `name`، و`english`، و`code`، و`year`، و`semester`، و`creditHours`، و`category`، و`description`، و`topics`، و`resources`.
- أنواع المصادر المتاحة: `توثيق رسمي`، `مسار تعلم`، `مرجع إضافي`، `ملزمة PDF`، `ملخص`، `فيديو`، `برنامج`، `اختبار`، `تطبيق عملي`.
- رابط المصدر `url` يمكن أن يكون رابطًا رسميًا أو ملف PDF داخل `public`، مثل `/files/database-lecture-1.pdf`.
- لا تضف ملفات أو كتبًا لا تملك حق إعادة نشرها. استخدم الروابط الأصلية عند الحاجة.
- إذا تغيّر رابط مصدر لاحقًا، يمكن تحديث ملف `data.ts` وإعادة رفع الموقع.

مثال مورد:

```ts
{ title: 'تحميل Visual Studio Code', kind: 'برنامج', description: 'محرر الأكواد', url: 'https://code.visualstudio.com/download' }
```

## الملفات المهمة

- `src/App.tsx`: الواجهات والتفاعل بين الصفحات.
- `src/style.css`: تصميم الوضع الليلي الأصلي.
- `src/themes.css`: الوضع النهاري وتبديل الألوان.
- `src/data.ts`: المعلومات والمقررات والمصادر.
- `public/assets/`: شعارا Tech Elite وصورتا الطالب.
- `demo.html`: المعاينة السريعة المستقلة.

## ملاحظات مهمة

1. لم تُثبت الخطة الدراسية النهائية بعد، لذا جميع أسماء ورموز المقررات في `courses` أمثلة غير معتمدة.
2. المحتوى الفعلي للدفعة مثل الصور والإنجازات سيضاف لاحقًا.
3. صورة الطالب هي **رسم ثابت بمظهر ثلاثي الأبعاد وتأثيرات حركة CSS** وليست مشهد WebGL ثلاثي الأبعاد تفاعليًا، حفاظًا على سرعة الموقع وسهولة استضافته مجانًا.
4. المشروع لا يحتاج قاعدة بيانات ولا API ولا نظام اشتراكات.
